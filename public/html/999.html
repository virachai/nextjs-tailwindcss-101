การออกแบบ Toggle Switch

Toggle switch นี้แสดงข้อความภายในตัวสวิตช์เอง ทำให้ผู้ใช้เข้าใจสถานะปัจจุบันได้ง่ายขึ้น

  • สีแดง: รับบริจาคเท่านั้น
  • สีเขียว: รับบริจาคและขาย

ข้อความภายในสวิตช์จะเปลี่ยนความโปร่งใสตามสถานะเพื่อให้ผู้ใช้เข้าใจได้ง่าย

// JavaScript สำหรับควบคุม toggle switch const toggleCheckbox = document.querySelector('.toggle-checkbox'); toggleCheckbox.addEventListener('change', function() { // ไม่ต้องเขียนโค้ดเพิ่มเติมเพราะใช้ CSS สำหรับการเปลี่ยนสถานะ console.log(this.checked ? 'โหมด: รับบริจาคและขาย' : 'โหมด: รับบริจาคเท่านั้น'); });
